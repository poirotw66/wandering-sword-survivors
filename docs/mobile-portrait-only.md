# Mobile portrait-only

Phones are locked to **portrait** (`sensor_portrait` / PWA portrait).

- Landscape on phone-like devices shows「請直向持機遊玩」
- Hub start-style picks use a 2×2 grid in portrait
- Desktop / non-phone windows stay ungated
- In-run combat on portrait phones uses a tighter camera zoom (`1.85`) and larger player/enemy sprites (`×1.35`) so actors stay readable; hitboxes are unchanged
