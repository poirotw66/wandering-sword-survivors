# 霧峽十五刻｜手動試玩與平衡矩陣（Godot）

適用於 Godot 重製版第一章 `chapter.mist_ravine`（900 秒）。本清單取代舊 Phaser 30 分鐘清單作為第一公開章節的手動驗收依據；自動化加速驗證見 `npm run godot:test`（含 `run_full_validation`）。

## 環境設定

| 平台 | 建議跑法 |
| --- | --- |
| 桌面 | 本機 Godot 編輯器執行，或 Web 匯出後以 1280×720 視窗開啟 |
| 橫向手機／平板 | 同一 Web 建置；鎖定橫向；目標約 1280×720 邏輯解析度（`keep` 比例） |
| 自動化對照 | `npm run godot:test`（內容規則 + 短煙霧 + 四路數加速全章） |

**請勿**在正式平衡觀察中依賴自動化的時鐘跳躍或無敵血量；那些僅供 CI 契約檢查。

## C. 時間里程碑（5／10／15 分）

對**至少兩種**路數完整走到通關；其餘路數可用中段抽樣。每格填：通過／失敗 + 簡短筆記。

| 時間 | 檢查項 | 桌面 | 橫向行動 | 量化通過標準 |
| --- | --- | --- | --- | --- |
| 0:00–5:00 | 小兵可清、升級三選一可讀 | | | 首升級 ≤ 約 60s；選卡文字完整可點 |
| 5:00 | 青崖執法出現＋可辨識預警 | | | Boss 約在 5:00±10s；簽名招有預警 |
| 5:00 後 | 突變二選一（不可跳過） | | | 恰 2 張；選定後立刻改行為／解鎖 |
| 5:00–10:00 | 中段壓力可讀、不軟鎖 | | | 螢幕敵數可辨；玩家非無腦碾壓也非必掛 |
| 10:00 | 赤砂宗主＋不同簽名 | | | 與 5 分 Boss 手感可區分 |
| 10:00 後 | 第二次突變二選一 | | | 恰 2 張；與第一次突變池不同 |
| 10:00–15:00 | 後期波次仍可操作 | | | 無長時間卡死；HUD 時間／血量可讀 |
| 15:00 | 霜峰劍魔（最終） | | | 約 15:00 出現；擊敗後**無**突變面板 |
| 通關 | 勝利結算＋存檔解鎖 | | | 解鎖九劍一閃路／意路數／對應心法；章節通關次數 +1 |

## E. 平衡矩陣（填數字或等級）

評分：1=過弱／過易，3=目標，5=過強／過難。同一場註明路數與裝置。

| 指標 | 定義／量法 | 劍 | 氣 | 身 | 意 | 目標帶 | 判定 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 早期清場 | 1–3 分對普通小兵 | | | | | 2–4 | 任一路數 1 或 5 → 失敗 |
| 升級節奏 | 5:00 時等級 | | | | | 約 Lv4–8 | 低於 3 或高於 10 → 需記筆記 |
| 5 分 Boss TTK | 執法戰時長（秒） | | | | | 20–90s | <10s 或 >150s → 失敗 |
| 10 分 Boss TTK | 宗主戰時長（秒） | | | | | 30–120s | <15s 或 >180s → 失敗 |
| 15 分 Boss TTK | 劍魔戰時長（秒） | | | | | 45–180s | <20s 或無法擊殺 → 失敗 |
| 受傷壓力 | 非 Boss 時段掉血感受 | | | | | 2–4 | 全程無傷或必掛 → 失敗 |
| 突變影響 | 選定後 30s 內可感知 | | | | | 必須可感知 | 無感 → 失敗 |
| 路數辨識度 | 換路數重開是否不同 | | | | | 明顯不同 | 四路同質 → 失敗 |
| HUD 可讀 | 時間／血／選卡 | 桌面 | 橫向 | — | — | 不遮擋關鍵資訊 | 擋操作 → 失敗 |
| 觸控操作 | 移動＋衝刺＋選卡 | — | 橫向 | — | — | 誤觸 < 2 次／場 | 無法通關級誤觸 → 失敗 |

## F. 裝置專項

### 桌面

- [ ] WASD／方向鍵移動穩定
- [ ] 空白鍵衝刺、爆發鍵可用
- [ ] Esc 暫停不破壞選卡狀態
- [ ] 1280×720 比例下 UI 無裁切

### 橫向行動

- [ ] 虛擬搖桿不遮 Boss 血條與選卡
- [ ] 衝刺／爆發鈕可單手點到
- [ ] 升級／突變卡可捲動或完整顯示
- [ ] 旋轉為直向時仍可暫停退出（不要求直向完玩）

## G. 整包通過標準（手動）

1. **至少一路數**完整 15 分鐘通關（桌面或橫向其一）。
2. **四路數**皆完成至少到 5:00 的差異抽樣。
3. Boss 順序與突變契約表全過。
4. 平衡矩陣無「整列失敗」；若有單一 1／5，須留下可執行調參筆記。
5. 無阻擋性 UI／缺字／存檔解鎖錯誤。
