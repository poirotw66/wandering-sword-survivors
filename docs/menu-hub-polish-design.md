# Menu Hub Polish Design

## Goal

Strengthen the desktop first viewport as a wuxia title composition while keeping run setup editable on the same screen. Mobile stays single-column and scrollable.

## Direction (approved)

- Atmosphere: ink-sword gold beam
- Layout: refined dual-column hub on desktop
- CTA: large Start only; Codex / Renown Shop as compact top-bar chips

## Desktop (>=900px, not mobile hub)

1. Top bar: Codex + Shop (left chips), renown/title (center), language + mute (right)
2. Left brand column: eyebrow, hero title, pitch, Start CTA, one-line run summary, next-goal line
3. Right narrow scroll panel: difficulty / start style / encounter (compact tiles)
4. Background: existing ink mountains + diagonal gold sword beam + light petals
5. Footer: keyboard hints only (no secondary action buttons)

## Mobile / narrow

1. Keep scrollable run-config panel
2. Move Codex / Shop into top bar as compact chips
3. Brand header stays short; Start remains the large bottom CTA
4. Hide pitch when space is tight

## Out of scope

- New meta systems
- Full art asset replacement
- Changing run-modifier / difficulty rules
